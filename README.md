# 유니트론텍 교육안내

2026년 10월 A/B그룹 수강생 안내 페이지입니다. 공개 파일은 `dist/`에만 위치합니다.

- `dist/content.js`: 회차별 일정과 커리큘럼
- `dist/index.html`: 교육명, 준비·출석·장소·문의 안내
- `dist/assets/`: 고객사와 솔트룩스 로고 원본

다음 고객사에는 폴더를 새로 복제하고 교육정보와 고객사 로고를 변경합니다. 지난 교육 폴더는 보존합니다. 현재는 정적 템플릿이며 관리자 입력·게시 기능은 아직 포함하지 않습니다. 교육장 안내는 하단 details 영역으로 분리했습니다.

식사 제공 여부와 미확정 강사 프로필은 기재하지 않았습니다. PDF보다 사용자가 확정한 계정 제공·설치 범위·온톨로지 범위를 우선합니다.
